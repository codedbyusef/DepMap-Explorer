# Data

DepMap Explorer does not ship any data files. The app reads preprocessed Parquet files from this folder, and you build them once with `preprocess.R`. The Parquet files are gitignored.

## Get the data

Option 1, download the prebuilt files (about 470 MB) from the GitHub Release `data-22Q2`:

```
Rscript requirements.R
Rscript get_data.R       # downloads into data/ and checks each file against checksums.txt
```

Option 2, build them from DepMap yourself (below).

## Build

```
Rscript requirements.R   # installs everything, including the build-only packages
Rscript preprocess.R     # writes the Parquet files below into data/
```

`preprocess.R` loads the four DepMap tables from **Bioconductor** through **ExperimentHub** (the `depmap` package). The first run downloads them into the ExperimentHub cache, so it needs an internet connection and takes a while. The app itself never calls `depmap` or `ExperimentHub`.

## Files

| File | Contents |
|---|---|
| `crispr.parquet` | CRISPR gene effect (Chronos) per cell line and gene, sorted by gene |
| `copy_number.parquet` | log2 copy number per cell line and gene, sorted by gene |
| `mutations.parquet` | mutation calls per cell line and gene, sorted by gene |
| `meta.parquet` | cell line name, primary disease, lineage |
| `lineage_effects.parquet` | Cohen's d, Welch p and BH q for every gene, each lineage vs all other lineages (lineages with at least 5 lines) |
| `go_enrichment.parquet` | GO Biological Process terms under cell death (GO:0008219) enriched among each lineage's selective dependencies |

The three large tables are sorted by gene and written in small row groups, so `arrow` reads only the rows for the selected gene.

## Source and license

## Source, license and changes

These files are **derived data**, not the original DepMap files. They come from DepMap Public **22Q2** (Broad Institute, https://depmap.org), read through the Bioconductor `depmap` package. I selected columns, joined and filtered tables, computed per-lineage statistics and GO enrichment, and re-saved everything as Parquet. DepMap data generated by the Broad are offered under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), which requires attribution, a link to the license and a note that changes were made (this section). Data from other projects hosted on the DepMap portal can carry different licenses, so check the license shown for each file in the portal's download panel. Cite DepMap as the portal asks.

22Q2 is not the newest DepMap release. The Bioconductor `depmap` package stops at 22Q2, so a newer release has to be read from Broad's own files, which `preprocess.R` does not do yet.

## Deploying

The app stops at startup with a message if a file is missing. For shinyapps.io, run `Rscript get_data.R` on your machine just before `rsconnect::deployApp()` so the Parquet files go into the bundle. The bundle limit on the Free and Starter plans is 1 GB and these files take about 470 MB. This avoids a 470 MB download every time an idle instance restarts.

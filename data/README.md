# Data

DepMap Explorer does not ship any data files. The app reads preprocessed Parquet files from this folder, and you build them once with `preprocess.R`. The Parquet files are gitignored.

## Get the data

Option 1, download the prebuilt files (about 725 MB) from the GitHub Release `data-24Q4`:

```
Rscript requirements.R
Rscript get_data.R       # downloads into data/ and checks each file against checksums.txt
```

Option 2, build them from DepMap yourself (below).

## Build

```
Rscript requirements.R   # installs everything, including the build-only packages
Rscript preprocess.R     # writes the Parquet files below into data/
```

`preprocess.R <raw_dir>` reads four files from the DepMap Public 24Q4 download (`CRISPRGeneEffect.csv`, `OmicsCNGene.csv`, `OmicsSomaticMutations.csv`, `Model.csv`). It reads the wide tables in gene chunks to keep memory low, but still run it under a cap so it cannot starve the machine: `systemd-run --user --scope -p MemoryMax=5G -p MemorySwapMax=0 Rscript preprocess.R <raw_dir>`. The app never reads the raw files.

## Files

| File | Contents |
|---|---|
| `crispr.parquet` | CRISPR gene effect (Chronos) per cell line and gene, sorted by gene |
| `copy_number.parquet` | log2 copy number per cell line and gene, sorted by gene |
| `mutations.parquet` | mutation calls per cell line and gene, sorted by gene |
| `meta.parquet` | cell line name, primary disease, lineage |
| `lineage_effects.parquet` | Cohen's d, Welch p and BH q for every gene, each lineage vs all other lineages (lineages with at least 5 lines) |
| `go_enrichment.parquet` | GO Biological Process terms under cell death (GO:0008219) enriched among each lineage's selective dependencies |

The three large tables are sorted by gene and written in small row groups, so `arrow` reads only the rows for the selected gene.

## Source and license

## Source, license and changes

These files are **derived data**, not the original DepMap files. They come from DepMap Public **24Q4** (Broad Institute, https://depmap.org), read from the release CSV files. I selected columns, joined and filtered tables, computed per-lineage statistics and GO enrichment, and re-saved everything as Parquet. DepMap data generated by the Broad are offered under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), which requires attribution, a link to the license and a note that changes were made (this section). Data from other projects hosted on the DepMap portal can carry different licenses, so check the license shown for each file in the portal's download panel. Cite DepMap as the portal asks.

## Deploying

The app stops at startup with a message if a file is missing. For shinyapps.io, run `Rscript get_data.R` on your machine just before `rsconnect::deployApp()` so the Parquet files go into the bundle. The bundle limit on the Free and Starter plans is 1 GB and these files take about 725 MB. This avoids a 470 MB download every time an idle instance restarts.
